# Misconfiguration Rubric (การกำหนดเวกเตอร์ CVSS v3.1)

## 1. ตาราง Rubric

ตารางนี้กำหนดเวกเตอร์ CVSS v3.1 ให้กับ misconfiguration แต่ละคลาสเพื่อใช้คำนวณความน่าจะเป็นผ่านโมเดลที่ fit กับข้อมูล CVE จริง โดยคอลัมน์ `conf` แสดงระดับความมั่นใจของการกำหนดเวกเตอร์ (อ้างอิงจำนวน CVE จริงในแต่ละ CVSS cell จาก `scripts/calibrate_rubric.py` สำหรับใช้ประกอบการวิเคราะห์ในรายงาน) และโมเดลใช้ตัวแปร Base Metrics ทั้ง 8 ตัวแยกกัน (`AV/AC/PR/UI/S/C/I/A`) โดยไม่ผ่านคะแนนรวม Base Score

## 2. เกณฑ์การกำหนดเวกเตอร์

1. **ประเมินเทียบกับโหนดต้นทาง (`u`)**: เวกเตอร์แต่ละแถวอธิบายการเคลื่อนที่หนึ่งก้าว (`u → v`) โดยถือว่าผู้โจมตีอยู่ที่สถานะ `u` แล้ว ดังนั้นค่า `AV` และ `PR` จึงวัดจากตำแหน่งและสิทธิ์ที่มีอยู่ ณ โหนด `u`
2. **การแยก `p_source` ด้วย Impact (`C/I/A`)**:
   - หาก `C:N/I:N/A:N` ทั้งสามค่า หมายถึงก้าวนั้นให้เฉพาะการเข้าถึงเชิงโครงสร้าง (reachability) ไม่มีการโจมตีเพื่อยกระดับสิทธิ์ จึงกำหนดเป็น `deterministic` (`p = 1.0`) และไม่นำเข้าฟังก์ชัน fit
   - หากมีผลกระทบต่อ `C`, `I` หรือ `A` อย่างน้อยหนึ่งตัว จะจัดเป็น `fitted` และคำนวณค่าความน่าจะเป็นจากโมเดลที่ฝึกไว้
   - ค่า `expert` สงวนไว้เป็นค่าสำรองเมื่อต้องการกำหนดความน่าจะเป็นโดยตรงหรือเมื่อคลาสไม่อยู่ในตาราง
3. **ขอบเขต `Scope (S)`**: กำหนดเป็น `S:C` เมื่อการเคลื่อนที่ข้ามขอบเขตการควบคุมสิทธิ์ (เช่น จากเครื่องในองค์กรไปสู่บัญชีคลาวด์ หรือข้ามบัญชี AWS) และเป็น `S:U` เมื่อยังอยู่ภายใต้ระบบจัดการสิทธิ์เดิม
