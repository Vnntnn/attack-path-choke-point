\frontchapter{กิตติกรรมประกาศ}
\setlength{\parindent}{1.25cm}
โครงงานนี้สำเร็จลุล่วงได้ด้วยความกรุณาจาก \Advisor{} อาจารย์ที่ปรึกษา ที่ให้คำแนะนำและข้อเสนอแนะตลอดการทำโครงงาน
ผู้จัดทำขอขอบพระคุณเป็นอย่างสูงมา ณ โอกาสนี้

ขอขอบคุณคณะเทคโนโลยีสารสนเทศ สถาบันเทคโนโลยีพระจอมเกล้าเจ้าคุณทหารลาดกระบัง
ที่ให้ความรู้และสภาพแวดล้อมในการศึกษา รวมถึงครอบครัวและเพื่อน ๆ ที่ให้กำลังใจตลอดการทำโครงงาน
