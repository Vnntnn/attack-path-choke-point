# เอกสารรายงานฉบับสมบูรณ์ (LaTeX)

โครงสร้างรายงานจัดตามรูปแบบของสถาบันเทคโนโลยีพระจอมเกล้าเจ้าคุณทหารลาดกระบัง แบ่งเป็น บทคัดย่อ, บทที่ 1 บทนำ, บทที่ 2 สิ่งที่ศึกษา, บทที่ 3 เนื้องาน, บทที่ 4 ประเมินผล อภิปราย และวิเคราะห์, บทที่ 5 สรุป และภาคผนวก ก–ง

## การคอมไพล์ไฟล์ PDF

```bash
docs/report/build.sh          # สร้างไฟล์ docs/report/build/pdf/main.pdf
```

ต้องติดตั้ง `uv` และ **tectonic** (XeTeX engine):

```bash
sudo pacman -S tectonic
```

## โครงสร้างไฟล์

| ไฟล์ | รายละเอียด |
|---|---|
| `meta.tex` | ชื่อเรื่อง (ไทย/อังกฤษ), ชื่อผู้จัดทำ, อาจารย์ที่ปรึกษา, ปีการศึกษา |
| `front.tex`, `abstract.tex` | หน้าปก, รายชื่อสมาชิกและหน้าที่, บทคัดย่อภาษาไทยและอังกฤษ, สารบัญ |
| `chapters/ch1.tex`, `ch2.tex`, `ch4.tex`, `ch5.tex`, `ch6.tex`, `refs.tex`, `appendix.tex` | เนื้อหาแต่ละบท เอกสารอ้างอิง และภาคผนวก (ลำดับการแสดงผลควบคุมผ่าน `\input` ใน `main.tex`) |
| `main.tex` | การตั้งค่าหน้ากระดาษ ฟอนต์ รูปแบบหัวข้อ และสารบัญ |
| `thai_zwsp.py` | สคริปต์แทรกจุดตัดคำภาษาไทย (U+200B) ลงในสำเนาไฟล์ก่อนคอมไพล์ด้วย XeTeX |
| `fonts/THSarabunNew*.ttf` | ฟอนต์สารบรรณ (`TH Sarabun New`) สำหรับคอมไพล์เอกสาร |

## การตรวจสอบความถูกต้องของตัวเลข

หลังจากแก้ไขตัวเลขใน `chapters/` หรือ `abstract.tex` สามารถรันสคริปต์ตรวจสอบความตรงกันของตัวเลขกับไฟล์ผลลัพธ์ใน `results/` และ `data/fit/` ได้ด้วยคำสั่ง:

```bash
uv run python scripts/check_claims.py
```
